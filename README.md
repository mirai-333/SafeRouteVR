# SafeRoute VR

VRを用いた地震・津波避難訓練システムです。  
大学の卒業研究として、避難行動の迅速化と災害リスクへの認識向上を目的に企画・開発しました。

## Overview

災害発生時に、正しい避難方法を一方的に提示するのではなく、  
限られた情報や時間の中で周囲の状況を確認し、ユーザー自身が判断して行動することを重視したVR避難訓練です。

屋内・屋外の2つのシナリオを制作し、Meta Quest上で体験できるよう開発しました。

## My Role

個人で企画・設計・開発・ユーザーテストまで担当しました。

主に以下のシステムを実装しています。

- シナリオ進行管理
- プレイヤーの行動判定
- 制限時間の管理
- クリア条件
- 正誤判定
- 結果表示
- シーン遷移
- その他インタラクション

開発後にはユーザーテストを実施し、体験前後の避難行動や災害リスク認識の変化を分析しました。

## Development Focus

開発では「VRだからこそ、どのような避難体験をつくれるか」を意識しました。

単に操作や機能を実装するだけでなく、ユーザーにどのような判断をしてほしいか、どのような状況で迷いや緊張が生まれるかを考えながら、体験全体を設計しています。

実装後も実際にプレイしながら、意図した体験になっているかを確認し、改善を繰り返しました。
